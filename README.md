# Universal Controller MIDI — release binaries

Built artefacts only. The application source is private.

Downloads for every platform are at **<https://midi.aidxn.com/downloads>**,
which resolves the right build for your OS. The assets attached to the
releases here are what that page serves.

## Why this repo exists

The app repo is private — the software is sold — which also makes its release
assets private. The storefront redirects downloads at those assets, so a
customer clicking Download got a 404. This repo holds the built zips publicly
so that link works.

That is not a bypass. The app is freemium: without a licence it runs the free
tier, and the mapping editor, presets, multi-controller and OSC output stay
locked behind an Ed25519-signed key. **The key is the paywall, not the
download.**
